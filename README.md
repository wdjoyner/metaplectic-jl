# Metaplectic Jacquet-Langlands Transfer

Research papers on metaplectic Jacquet-Langlands transfer
for division algebras of prime degree.

## Manuscripts

- Part I: Covering-theoretic foundations
- Part II: Local test-function matching
- Part III: Division-algebra character transforms
- Part IV: Wild local correspondence and global trace
  formula comparison

Each part contains its current LaTeX manuscript,
compiled PDF, and revision log.

## Research status

This is ongoing mathematical research.

The manuscripts distinguish complete proofs,
established results from the literature, conditional
statements, and open conjectures.

The full metaplectic Jacquet-Langlands correspondence
is not claimed to have been established.

Comments, corrections, and independent mathematical
referee reports are welcome through GitHub Issues.
